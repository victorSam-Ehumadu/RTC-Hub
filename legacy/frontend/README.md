# 💻 RTC Hub - Frontend (React)

The user-facing platform for Richfield students and recruiters. Built for speed and a "Terminal-style" professional aesthetic.

## 📁 Structure
- `/src/components`: Reusable UI like `CodeBlock`, `Heatmap`, and `BountyCard`.
- `/src/pages`: Main views: Dashboard (Feed), Portfolio (Proof of Work), and ShadowBridge.
- `/src/services`: Axios/Fetch configurations to communicate with the Node.js API.
- `/src/context`: Global state management for user sessions and Logic Points.

## 🎨 Design System
- **Framework:** Tailwind CSS.
- **Theme:** Dark Mode (Standard) to reduce eye strain for developers.
- **Visuals:** Recharts for Skill-Graph data visualization.

## 🚀 Deployment
- Run `npm install` followed by `npm start`.
