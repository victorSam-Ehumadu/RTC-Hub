🃏 Richfield Tech-Connect Hub (RTC Hub)
"Moving from Digital Resumes to Verifiable Proof of Work"

🎯 Executive Summary
The RTC Hub is a specialized professional ecosystem designed specifically for the Richfield College community. While platforms like LinkedIn are saturated with general "corporate noise," RTC Hub focuses on Technical Signal. By integrating live code execution, peer-to-peer micro-mentorship, and module-verified skills, we provide a platform where actual competence outshines networking.

### 🚀 Getting Started
1. **Database:** Set up Supabase using the `/supabase` migrations.
2. **Server:** Start the Node/Express API in `/backend`.
3. **Client:** Launch the React UI in `/frontend`.

🛠️ Tech Stack
Frontend: React.js, Tailwind CSS (for the "Terminal/Casino" aesthetic), Recharts.

Backend: Node.js, Express.js.

Database & Auth: Supabase (PostgreSQL + Realtime).

Code Execution: Prism.js (Syntax) / Judge0 API (Execution).

### 🏆 Hackathon Edge
Our platform bridges the gap between the classroom and the workplace by turning academic success (Richfield Modules) into visual, verifiable data for recruiters.
