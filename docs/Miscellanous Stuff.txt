To push to repo (for my fork atleast):
1.  git status -s (or git diff)
   (before adding is the habit that prevents surprises
   — check what's changed, decide what belongs together, then stage that.)
2. git add -A (or git add <specific files>)
  (To stage all unstaged files)

3. git commit -m "your message here"

4. git push fork main
